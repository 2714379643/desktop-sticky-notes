# Desktop Sticky Notes 1.1 导入模板
# 文件编码必须为 UTF-8。
# 每一行是一项任务，字段之间使用英文竖线 | 分隔。
# 格式：日期|开始时间|结束时间|任务内容|重复规则|星期|每月日期|每日开始|每日结束
# 重复规则：none（不重复）、daily（每天）、weekly（每周）、monthly（每月）
# 每周任务在“星期”中填 1 到 7，依次代表星期一到星期日。
# 每月任务在“每月日期”中填 1 到 31；短月份会自动使用最后一天。
# 每日任务的开始、结束日期都可单独留空；旧版 5/7 字段模板仍可导入。
# 不设置时间时，开始和结束字段都留空，但两个竖线仍要保留。
date|start_time|end_time|title|repeat|weekday|month_day|repeat_start|repeat_end

2099-09-09|||每日阅读|daily|||2099-09-12|2099-10-12
